# iconnect · 局域网文件传输

> 一个基于 Tauri 的桌面应用，让你在**同一局域网**内，用手机和电脑互传文件、图片和文本 —— 不需要数据线，不需要登录账号，不需要通过第三方服务器。

## 为什么需要它？

日常手机和电脑之间传文件，总绕不开这些痛点：

- 📱 微信/QQ 传文件：需要登录、有大小限制、画质被压缩，还可能跑到公网服务器上绕一圈
- 🔌 数据线传输：每次都要找线、插线、授权，麻烦且容易忘
- ☁️ 网盘中转：上传再下载，速度取决于公网带宽，还受文件大小限制
- 📡 蓝牙：速度慢，只支持近距离，大文件体验很差

**iconnect 的解法**：电脑端启动一个本地 HTTP 服务，手机用浏览器打开二维码一扫即连。文件直接在局域网内传输，**不经过任何第三方服务器**，数据不出内网，快速且安全。

## 功能特性

- 📁 **手机 → 电脑**：发送任意文件 / 图片（支持多选），自动保存到电脑指定目录
- 🖥️ **电脑 → 手机**：选择文件 / 图片发送到手机，手机端一键下载
- 💬 **双向文本传输**：手机和电脑之间互发文字，像聊天一样简单
- 📱 **零安装手机端**：手机无需安装任何 App，浏览器扫码即用
- 🔗 **二维码连接**：电脑端展示二维码，手机扫码自动打开对应页面
- 🚀 **大文件支持**：4MB 分片并发上传，断网自动重试，传输稳定不占满内存
- 📜 **历史记录**：自动保存接收文件的历史，随时打开所在文件夹
- 🗂️ **重名自动改名**：同名文件自动追加 `(1)`、`(2)` 序号，不会覆盖

## 快速开始

### 环境要求

- 电脑安装 [Node.js](https://nodejs.org/)（含 npm）
- 电脑安装 [Rust](https://www.rust-lang.org/)（Tauri 2 依赖，若使用预编译安装包则无需）
- 手机与电脑连接**同一个局域网**（同一 Wi-Fi 或路由器）

### 开发运行

```bash
npm install
npm run tauri dev
```

### 打包安装包

```bash
npm run tauri build
```

构建产物位于 `src-tauri/target/release/bundle/`，可分发安装。

> 也可以直接下载 Releases 中的安装包使用，无需搭建开发环境。

## 使用教程

### 第一步：电脑端启动服务

1. 打开 iconnect，界面左侧显示服务状态。
2. 点击 **「启动服务」**，电脑会自动监听一个空闲端口，并显示：
   - 局域网访问地址（如 `http://192.168.1.100:34567`）
   - 对应的**二维码**
3. 如需要，可点击 **「选择目录」** 修改手机文件接收后的保存位置（默认保存到「下载」文件夹），并可通过 **「打开目录」** 随时打开该文件夹。

### 第二步：手机连接电脑

任选一种方式：

- **扫码**：用手机浏览器（或相机）扫描电脑屏幕上的二维码，自动打开连接页面
- **手动输入**：在手机浏览器地址栏输入电脑上显示的 `http://IP:端口` 地址

手机页面显示「传送到电脑」，即连接成功。**关闭页面即断开，无需退出登录。**

### 第三步：开始传输

#### 📁 手机 → 电脑

| 内容 | 操作方式 |
| --- | --- |
| 文件 / 图片 | 点击左下角 **「+」** 按钮，选择「发送文件」或「发送图片」，支持多选 |
| 拖拽 | 在手机页面上直接**拖拽文件**到聊天区域（电脑浏览器同样支持） |
| 文本 | 在底部输入框输入文字，点击「发送」 |

上传时聊天气泡会实时显示进度百分比，完成后显示 ✓。文件自动保存到电脑上第一步设置的目录中，并出现在电脑端的接收历史里。

#### 🖥️ 电脑 → 手机

| 内容 | 操作方式 |
| --- | --- |
| 文件 / 图片 | 点击聊天窗口下方的 **「+」** 按钮，选择「发送文件」或「发送图片」 |
| 文本 | 在聊天窗口输入文字，按回车或点击「发送」 |

手机页面会**实时弹出**（通过 SSE 推送，无需刷新），文件气泡上出现「下载」按钮，点击即可保存到手机。

### 第四步：查看与管理

- 电脑端聊天窗口会同步显示收发记录；底部「历史记录」列出所有从手机接收的文件，点击「打开」直达文件所在文件夹
- 手机端收发内容同样以聊天形式保留在页面上

## 工作原理

```
┌─────────────┐   HTTP (局域网)   ┌──────────────────┐
│  手机浏览器   │  ──────────────►  │  电脑 iconnect    │
│  (零安装)    │  上传文件 / 文本   │  axum 本地服务    │
│             │  ◄──────────────  │  保存到指定目录    │
│             │  SSE 推送 / 下载   │                   │
└─────────────┘                   └──────────────────┘
       所有数据仅在局域网内传输，不经过任何第三方服务器
```

- **上传**：手机端将大文件切成 4MB 分片，最多 2 个文件并发上传，单个分片失败自动重试（最多 3 次），全部到齐后由服务端合并落盘
- **下行推送**：电脑端通过 SSE（Server-Sent Events）实时把文件/文本推送到手机页面
- **安全**：服务只监听局域网地址、随机端口；文件名经过清洗防路径穿越；每次启动自动清理临时分片文件
- **连接**：自动获取本机局域网 IP，二维码开箱即用

## 技术栈

| 端 | 技术 |
| --- | --- |
| 桌面端框架 | [Tauri 2](https://tauri.app/) + Rust |
| HTTP 服务 | [axum](https://github.com/tokio-rs/axum) + tokio |
| 前端 | Vanilla TypeScript + [Vite](https://vitejs.dev/) |
| 二维码 | `qrcode` crate（SVG 渲染） |
| 实时推送 | SSE（Server-Sent Events） |

## 常见问题

**Q：手机打不开连接页面？**
请确认手机和电脑连接的是同一个局域网；部分路由器开启了「AP 隔离」，需在路由器设置中关闭。

**Q：收到的文件保存在哪里？**
默认保存在电脑「下载」文件夹，可在启动服务前通过「选择目录」自定义。

**Q：传输安全吗？**
数据全程只在局域网内流转，不经过公网。服务仅在你主动启动时开放，关闭应用即停止监听。

**Q：能传多大文件？**
没有大小限制。大文件以 4MB 分片上传，稳定可靠。
